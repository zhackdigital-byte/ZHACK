# ZHACK

## Mess Bill Calculator

A modern, responsive web application for calculating and splitting monthly mess bills among 4 people.

### Features
- **Modern Design:** Sleek UI with glassmorphism effects and dark mode.
- **Fair Splitting:** Automatically calculates total expenses, per-head share, and exactly who owes whom.
- **Supabase Integration:**
  - Secure Email/Password Authentication.
  - Save calculated monthly reports directly to a Supabase database.
  - View and delete history of past reports.

### Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Supabase (Auth and PostgreSQL)
